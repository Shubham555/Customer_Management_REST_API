# FastAPI Customer Management REST API

A learning project built while studying FastAPI through 13 practical Sessions. Instead of learning FastAPI only as theory, the concepts were learned step by step by building a small Customer Management REST API.

## What this repository contains

- A working Customer Management REST API using FastAPI, Pydantic, SQLAlchemy and MySQL.
- Small practice files showing the code from each learning steps.
- Session notes covering the theory and concepts from all 13 steps.

## Tech stack

- Python
- FastAPI
- Uvicorn
- Pydantic
- SQLAlchemy
- PyMySQL
- MySQL
- HTTPX

## API endpoints

| Method | Endpoint | Description |
| --- | --- | --- |
| GET | `/` | Check that the API is working |
| POST | `/customers` | Create a customer |
| GET | `/customers` | Get all customers |
| GET | `/customers/{customer_id}` | Get one customer |
| PUT | `/customers/{customer_id}` | Update a customer |
| DELETE | `/customers/{customer_id}` | Delete a customer |

A customer has a `name`, `age` and `city`. The `id` is generated by MySQL. Requests for a customer ID that does not exist return `404 Customer not found`. Invalid request data returns `422`.

## Request flow

```
Client -> FastAPI endpoint -> Pydantic validation -> SQLAlchemy -> MySQL -> JSON response
```

## Setup

1. Create the database in MySQL:

```sql
CREATE DATABASE customer_management;
```

2. Install the dependencies:

```
pip install -r requirements.txt
```

3. Open `database.py` and replace `YOUR_USERNAME` and `YOUR_PASSWORD` in `DATABASE_URL` with your MySQL credentials. If the password contains special characters such as `@` or `/`, encode them in the URL. Do not commit real credentials.

4. Run the application:

```
uvicorn main:app --reload
```

The `customers` table is created automatically on startup.

## Testing

Open `http://127.0.0.1:8000/docs` and test in this order:

1. `POST /customers` with:

```json
{
  "name": "Rahul",
  "age": 25,
  "city": "Pune"
}
```

2. `GET /customers`
3. `GET /customers/1`
4. `PUT /customers/1` with a new age or city
5. `DELETE /customers/1`
6. `GET /customers` to confirm the record is gone

## Running the practice files

Run these from the project root. Each file is a separate small app.

```
uvicorn practice.session_01_first_app:app --reload
```

Replace the module name for other sessions, for example `practice.session_05_pydantic`. The authentication example (Session 11) accepts the bearer token `demo-token` through the Authorize button in `/docs`. The external API example (Session 10) needs internet access.
